## Project title

Java Database Migration and SQL Performance Optimization

## Your role

Java Backend / Database Developer

## Project description

Built a self-initiated Java 17 and Spring Boot demonstration for reliable cross-database migration using synthetic data. The solution cleans legacy records, processes them in configurable batches, stores transactional checkpoints, resumes interrupted runs, and prevents duplicates through idempotent upserts. It verifies results with row counts and SHA-256 checksums. I also added an SQL performance module that compares EXPLAIN plans before and after a composite index, plus Swagger, Docker Compose, CI, and 8 integration tests.
